Controle de Estoque (TypeScript + Vite + Express + MySQL)
=========================================================

A explicacao completa (arquitetura, rotas, permissoes e como rodar) esta no README.md.

  index.html          a pagina (os ids sao usados pelo codigo)
  css/estoque.css     a aparencia (tema claro e escuro)
  src/                o front-end: tipos, api (fetch), servicos, dom e main
  api/src/            a API em camadas: rotas, servicos e dados
  sql/estoque.sql     cria o banco com as tabelas e os dados de exemplo

Como rodar (resumo)
1. Rode sql/estoque.sql no MySQL Workbench
2. Em api/, copie .env.exemplo para .env e preencha a senha e o JWT_SEGREDO
3. npm install && npm --prefix api install
4. npm run api  (um terminal)  e  npm run dev  (outro terminal)
5. Abra http://localhost:5173

Atencao: NAO abra o index.html com dois cliques; use o npm run dev.
